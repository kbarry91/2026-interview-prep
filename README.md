# 2026-interview-prep

## Purpose

This repo is intended as a preparation aid for technical interviews, especially those focused on backend design, algorithms, and system architecture.

## How to Use

1. Open the coding challenge files in [coding-challanges](coding-challanges) to study problem statements and solutions.
2. Read the system design notes in [system-design](system-design) for architecture patterns and tradeoffs.
3. Run, adapt, and extend the examples for practice and interview preparation.
