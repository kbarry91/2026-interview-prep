# 2026-interview-prep

This repository contains coding challenge implementations and system design notes prepared for interview practice. The `coding-challanges` folder includes .NET/C# solutions for common algorithm and design problems, while the `system-design` folder holds architecture discussions for a clinician chat platform.

## Table of Contents

- `coding-challanges/`
  - `DuplicateMessageDetector.cs` - Identifies duplicate messages in a stream or sequence to prevent repeated processing.
  - `GroupCliniciansByDepartment.cs` - Groups clinician data by department, useful for roster and directory organization.
  - `MessagePriorityQueue.cs` - Implements a priority queue for messages to support prioritized processing.
  - `MessageRateLimiter.cs` - Controls message throughput to enforce rate limits and avoid overload.
- `system-design/`
  - `SystemDesign_ClinicianChatPlatform.md` - Describes a clinician chat platform architecture, including key components, scaling considerations, and design tradeoffs.

## Purpose

This repo is intended as a preparation aid for technical interviews, especially those focused on backend design, algorithms, and system architecture.

## How to Use

1. Review the coding challenge files to understand the problem and solution approach.
2. Read the system design document for architectural reasoning and tradeoffs.
3. Adapt or extend the examples for your own interview preparation or implementation practice.
