5. Loops

// Standard for
for (int i = 0; i < n; i++) { }

// Reverse
for (int i = n - 1; i >= 0; i--) { }

// Enhanced for (read-only)
for (int x : arr) { }
for (String s : list) { }
for (Map.Entry<K, V> entry : map.entrySet()) {
    K key = entry.getKey();
    V val = entry.getValue();
}

// While
while (condition) { }

6. Common Patterns

Array to List

List<Integer> list = Arrays.asList(1, 2, 3);   // fixed size
List<Integer> list = new ArrayList<>(Arrays.asList(1, 2, 3));   // mutable

List to Array

int[] arr = list.stream().mapToInt(Integer::intValue).toArray();

Iterate Map

for (Map.Entry<String, Integer> e : map.entrySet()) {
    System.out.println(e.getKey() + " = " + e.getValue());
}

Build a frequency map

Map<Character, Integer> freq = new HashMap<>();
for (char c : s.toCharArray()) {
    freq.put(c, freq.getOrDefault(c, 0) + 1);
}

Sort with custom comparator

Arrays.sort(arr, (a, b) -> b - a);   // descending
Collections.sort(list, Comparator.reverseOrder());

7. Common Mistakes To Avoid

  • == for strings — wrong, use .equals()
  • arr.length() for arrays — wrong, no parentheses
  • list.length for lists — wrong, it's .size()
  • map.get(key) without null check when key may be absent
  • Modifying a collection while iterating with enhanced for — throws ConcurrentModificationException
  • Comparing Integer objects with == for large values — use .equals() or intValue()
  • Using HashMap (raw type) without <> — compiler warning

8. Five Things To Say In The First 5 Minutes

  1. Greet warmly — "Good to meet you both."
  2. Ask clarifying questions on the problem — null inputs, edge cases, constraints
  3. State approach in plain English BEFORE coding
  4. State time/space complexity BEFORE coding
  5. Talk through tests/edge cases when done
